# Path of Hero

Before doing anything in this repo, read [docs/README.md](docs/README.md): it indexes the project's
knowledge base (one purpose per document). Then read the documents your task touches, at least
[docs/dev-workflow.md](docs/dev-workflow.md) before running any command, and [docs/process.md](docs/process.md)
before committing. If `private/` exists here, read `private/CLAUDE.md` too.

Keep the docs true: a change in behaviour updates the document that describes it, in the same commit.
This repository is public: nothing private goes in (docs/process.md, "What never goes in").
